# 跳广告助手 (AdSkip)

参考 GKD 思路自研的 Android 无障碍跳广告 App。

## 能做什么

- **开屏广告**：监听窗口切换，自动扫描并点击「跳过 / 关闭 / Skip / ×」
- **应用内弹窗 / 暂停广告**：监听窗口内容变化，关闭带「关闭/跳过」的广告层
- **摇一摇广告**：检测到「摇一摇」文案时高频抢点跳过；免 root 无法从传感器层根治，需在系统里对目标 App 关闭「获取设备动作与方向」权限（App 内已附操作说明）

## 编译

push 到 GitHub 后，`.github/workflows/build.yml` 会在云端自动编译。
到 Actions 页下载 `adskip-apk` artifact，解压得到 `app-debug.apk` 即可安装。

debug 签名可直接安装（无需开发者证书）。若提示签名冲突，先卸载旧版。

## 安装与使用

1. 手机开启「安装未知应用」权限，安装 APK
2. 打开 App → 点「开启无障碍服务」→ 系统设置里打开本服务
3. 按 App 内提示，在 HyperOS 里开启：自启动、省电策略无限制、后台活动、最近任务加锁
4. 摇一摇根治：设置 → 应用管理 → 常误跳转的 App → 权限 → 关闭「获取设备动作与方向」

## 说明

- 仅个人学习使用，不保证 100% 跳过所有广告（各 App 实现不同，广告改版需更新匹配规则）
- 无网络权限、不收集任何数据
